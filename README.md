# Анализ и прогнозирование меты Dota 2 (патчи 7.30–7.35)

**Цель** — получить интерактивный Jupyter Notebook (Google Colab) с анализом данных о героях Dota 2, включая:
- ранжирование героев по винрейту и пикрейту в каждом патче,
- выявление «скрытых имб»,
- простой прогноз винрейта десяти выбранных героев на следующий патч.

Проект выполнен в рамках учебного курса по анализу данных на Python.

Dota 2 регулярно получает обновления баланса, меняющие силу героев. Понимание текущей меты и умение предсказывать тренды полезно как игрокам (выбор героя для повышения рейтинга), так и аналитикам. Проект демонстрирует, как с помощью открытых данных можно автоматизировать подобный анализ, заменяя субъективные впечатления объективными метриками.

## Обзор аналогов и прототипов
Существуют сайты вроде Dotabuff, Spectral.gg и Stratz, которые предоставляют детальную статистику героев, но:
- Они редко дают возможность гибко фильтровать данные по нескольким патчам одновременно.
- Не позволяют строить собственные прогнозы на основе исторических данных.
- Их интерфейс фиксирован, тогда как наш проект — полностью программируемый инструмент, который можно адаптировать под любые гипотезы.

Наше решение: открытый код, воспроизводимость, наглядные графики, простейшая модель прогноза, реализованная прямо в ноутбуке.

## Краткое описание реализованных задач

### Задача 1. Анализ текущей меты
Для каждого патча строятся:
- **Топ-10 героев по винрейту** (`Win Rate`) — горизонтальная столбчатая диаграмма.
- **Топ-10 героев по пикрейту** (`Pick Rate`) — аналогичный график.
- **Scatter-plot «Винрейт vs Популярность»**, на котором выделяются 5 персонажей с **низким пикрейтом, но высоким винрейтом** («скрытые имбы»). Их список и метрики выводятся таблицей.

### Задача 2. Прогноз винрейта на следующий патч
Для десяти выбранных героев (например, Pudge, Invoker, Meepo и др.) строится временной ряд их винрейта по патчам.  
Используя полиномиальную аппроксимацию (степень 1 или 2), вычисляется прогнозное значение для патча 7.36. Результат отображается в виде таблицы и линейного графика с продолжением линии прогноза.



### Сленг, используемый в проекте:
- **Винрейт** (от англ. win rate — процент побед) персонажа в Dota 2 — это соотношение выигранных матчей к общему числу игр на этом герое, выраженное в процентах.
- **Пикрейт** (от англ. pick rate — частота выбора) — это статистический показатель, который отражает, как часто игроки выбирают конкретного персонажа в матчах
- **Скрытые имбы** - это персонажи с низким пикрейтом, но высоким винрейтом
